# 高复用场景：一个引擎，五种问法

这个 Agent 的价值不在「能查一件事」，而在**同一套查证动作会被反复调用**。所以选场景的标准不是行业新不新，
而是三件事：

1. **调用频率**：同一类问题一天/一周被问几次
2. **人工成本**：人自己核一次要多久
3. **出错代价**：答错一次赔多少

按这三条排下来，以下五类是复用密度最高的。它们共用同一套检索层、裁决层、表达层，
差别只在 `app/domains/*.json` 这一个文件（约 30 行配置）。

---

## 一、复用矩阵

| 场景 | 典型调用入口 | 复用形态 | 人工核一次 | 答错的代价 | 复用强度 |
|---|---|---|---|---|---|
| 政策与补贴 | 老板/财务/项目申报 | 群机器人 + 静态卡 | 20–60 分钟（翻文件、找废止通知） | 按错的条件准备材料，错过申报窗口 | **极高**：每家中小企业每月都在问 |
| 资质与招投标 | 采购/投标/质检 | 浏览器插件 + API | 10–30 分钟（进官方库逐条查） | 用了失效证书被废标、被追责 | **极高**：一单一次，且必须留痕 |
| 健康与消费品说法 | 客服/内容审核/家族群 | 聊天机器人 + 小游戏 | 5–20 分钟（找权威说法） | 传谣、合规处罚、信任受损 | **极高**：一天几十条 |
| 财务与数据口径 | 投研/BD/销售 | API + 报告附件 | 30–120 分钟（对报表、核口径） | 拿错数字做决策、对外口径打脸 | **高**：季度密集、平时零散 |
| 劳动用工与合规 | HR/行政/老板 | 群机器人 + Skill | 15–40 分钟（翻法条、查地方细则） | 违法条款、仲裁败诉 | **高**：入职离职季爆发 |

「复用强度」是按使用结构判的，不是按行业规模：政策与资质是**固定动作反复做**，财务法务是**低频高价值**。

## 二、五个场景各自的关键口径

### 1. 政策与补贴（`--domain policy`）

| 项 | 内容 |
|---|---|
| 问句 | 「宁波市智能化改造项目最高补贴多少」「专精特新小巨人 2026 年申报条件」「研发费用加计扣除这条政策还有效吗」 |
| 一手源 | 各级政府门户、发改委、工信、财政、人社、地方经信局、浙江政务服务网 |
| 结论用语 | 现行政策支持 / 与现行政策不符 / 政策口径存在冲突 / 查不到官方原文 |
| 判定要点 | 文件是否现行有效、是否被新文件替代、条件是本地还是全国、金额是最高限额还是普惠标准 |
| 必排除 | 代办机构宣传、解读文章、转载稿 |

**为什么复用**：同一家企业一年要碰十几次政策问题，且每次都伴随「文件早就废止了但网上还在传」这个坑。

### 2. 资质与招投标（`--domain tender`）

| 项 | 内容 |
|---|---|
| 问句 | 「这家供应商的 3C 证书还有效吗」「该型号能效等级符合 GB 18613 吗」「ISO 9001 认证范围对得上吗」 |
| 一手源 | 全国认证认可信息公共服务平台、CQC、认监委、国家企业信用信息公示系统、国家标准全文公开系统 |
| 结论用语 | 资质有效，可采信 / 与官方登记不符 / 登记信息互相矛盾 / 官方库查不到记录 |
| 判定要点 | 「证书存在」≠「证书覆盖该型号」；「有效期至某日」≠「当前状态正常」 |
| 必排除 | 商家详情页、宣传册、B2B 平台自述 |

**为什么复用**：每次投标、每次换供应商都要查一遍，而且是**必须留痕**的动作——静态卡正好当证据附件。

### 3. 健康与消费品说法（`--domain health`）

| 项 | 内容 |
|---|---|
| 问句 | 「保鲜膜加热会释放致癌物吗」「这款保健品宣称能降血糖靠谱吗」「隔夜菜会致癌吗」 |
| 一手源 | 疾控、药监、食品安全风险评估中心、科普中国、联合辟谣平台、WHO、PubMed |
| 结论用语 | 真 / 假 / 说不准 / 没查到可靠来源（沿用通用用语，不美化） |
| 判定要点 | 「有风险」≠「致癌」；动物实验不能直接推人；保健食品不得宣称疗效 |
| 必排除 | 营销号、带货文案、个人体验 |

**为什么复用**：量最大、判断最快、最容易被随手转发。客服和内容审核用它，成本几乎为零。

### 4. 财务与数据口径（`--domain finance`）

| 项 | 内容 |
|---|---|
| 问句 | 「年报里的毛利率口径含不含运费」「这个数字出自哪份报告」「营收还是总营收」 |
| 一手源 | 巨潮资讯、沪深北交易所、证监会、港交所、SEC、统计局、央行 |
| 结论用语 | 与原始披露一致 / 与原始披露不符 / 口径不一致，数字无法对齐 / 查不到原始披露 |
| 判定要点 | 报告期是否一致、合并口径、含税与否、营业收入 vs 营业总收入 |
| 必排除 | 数据平台、券商研报、财经自媒体（只能当线索） |

**为什么复用**：所有对外材料、BP、投标书里的数字都过这一关，错一次要公开更正。

### 5. 劳动用工与合规（`--domain labor`）

| 项 | 内容 |
|---|---|
| 问句 | 「试用期最长可以约定多久」「离职补偿的 N 怎么算」「竞业限制补偿金最低标准」 |
| 一手源 | 中国人大网、最高法、人社部、地方人社厅、地方高院 |
| 结论用语 | 有明确法律依据 / 与现行规定相悖 / 存在地方差异或判例分歧 / 查不到权威条文 |
| 判定要点 | 必须分三层说：法条怎么写、地方怎么执行、个案怎么裁 |
| 特别处理 | 法条不按新闻时效衰减（`freshness_decay: false`），2019 年的条文今天照样有效 |

**为什么复用**：HR 问答是天然高频；而且「地方差异」这件事，只有把三层分开讲才不会误导。

## 三、同一套代码，只换配置

领域包只提供五类数据，架构一行不动：

```json
{
  "id": "tender",
  "authority":  { "t1": ["cx.cnca.cn", "..."], "t4": ["1688.com"] },
  "lexicon":    { "refute": { "已暂停": 3 }, "support": { "证书有效": 3 } },
  "labels":     { "false": "与官方登记不符" },
  "semantic_context": "本领域判定以官方登记库的查询结果为准……",
  "queries":    ["这家供应商的 3C 证书还有效吗"],
  "disclaimer": "证书状态随时可能变更……",
  "freshness_decay": true
}
```

对应生效的位置：

| 配置 | 生效位置 |
|---|---|
| `authority` | 信源分档，优先级高于内置白名单（同站不同行业分量不同） |
| `lexicon` | 词表兜底时补行业表述（「已暂停」「口径不一致」） |
| `semantic_context` | 语义判定的系统提示词，把行业口径讲给模型 |
| `labels` | 结论用语（财务说「与披露不符」，法务说「存在地域差异」） |
| `freshness_decay` | 法条/国标不按时效衰减 |
| `disclaimer` | 卡片底部免责说明 |

**新增一个行业 ≈ 写一个 30 行 JSON + 三条示例问句**，不用改 Python，不用重新训练。

## 四、商业化上的复用

同一套能力，不同场景换一个壳就能卖：

| 形态 | 面向 | 复用方式 |
|---|---|---|
| 群机器人 | 中小企业内部（政策、用工） | 一次部署，全公司问 |
| 浏览器插件 | 采购、投研、编辑 | 划词即查，结果存静态卡 |
| API | 客户自有系统（CRM、ERP、投标平台） | 按次计费，`/api/check` 直接接 |
| Skill / 工作流节点 | 已经在用 AI 工作台的团队 | 挂进现有流程，不换工具 |
| 静态卡导出 | 需要留痕的场合（投标、审计、合规） | 每张卡带指纹，可归档复核 |

对私域部署这条线尤其合适：**检索和模型都可以在客户内网，数据和提问不出门**，只需要一个出网的白名单出口调元宝搜索。

---

## 五、不适合用它做的事

诚实划界，避免把工具卖给不该用的场景：

- **需要专业判断而非事实核查的**：诊断疾病、判断合同条款是否对我方有利、给投资建议
- **答案不在公开互联网上的**：内部制度、客户私域数据、非公开报价
- **答案尚未产生的**：预测类问题（工具会明确回「没查到可靠来源」，这是正确行为）
- **涉及个人隐私与时政的**：检索层与规则层都主动不碰

## 六、怎么验证这些场景真的能用

```bash
python run.py "宁波市智能化改造项目最高补贴多少" --domain policy
python run.py "这家供应商的 3C 证书还有效吗"       --domain tender
python run.py "保鲜膜加热会释放致癌物吗"           --domain health
python run.py "年报里的毛利率口径含不含运费"        --domain finance
python run.py "试用期最长可以约定多久"             --domain labor
```

网页端左上角下拉框切换领域，示例问句、权威源、结论用语、免责声明整套一起换。
带 `?domain=policy` 可直接分享某个领域的入口。
